Proyecto de extracción

Define la pregunta y el contexto. Estos datos viajan con la tabla exportada hacia MetaAnálisisIA.

Puedes cambiar el esquema en el siguiente paso. El demo carga 3 estudios sintéticos para probar el flujo sin API key.

Esquema de extracción

Elige una plantilla o personaliza los campos. Cada campo se convertirá en una columna de la tabla final.

Fuentes (estudios)

Añade estudios pegando texto (abstract + results + tablas) o carga el demo. En v0.1 la entrada es texto; el PDF nativo queda para una versión posterior.

Configuración de IA (para proponer extracciones)

Solo se usa al pedir «Proponer con IA». El demo de extracción por reglas funciona sin clave.

Extracción asistida

Revisa cada campo. Aceptar confirma el valor; Corregir edita; sin aceptar no entra en la tabla final.

Principio: la IA (o las reglas) solo proponen. El estado «aceptado» lo decides tú. El export solo incluye celdas aceptadas o corregidas por humano.
